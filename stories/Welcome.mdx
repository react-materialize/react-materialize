# React Materialize

[![npm version](https://img.shields.io/npm/v/react-materialize.svg?style=flat)](https://npmjs.org/package/react-materialize)

Welcome to the **React Materialize** docs.

You should use **React Materialize** if you want to use
[materialize-css](https://materializecss.com) components in your React application.
This is only a wrapper around materialize-css for ease of use.
Navigate through these docs to see the available components; each component's **Docs** page shows its props and the source of every example.

```jsx
import { Modal, Button } from 'react-materialize';

const trigger = <Button>Open Modal</Button>;

export default () => (
  <Modal header="Modal Header" trigger={trigger}>
    Lorem ipsum dolor sit amet, consectetur adipiscing elit.
  </Modal>
);
```

## Installation

```sh
npm install materialize-css
npm install react-materialize
```

## HTML Setup

```html
<head>
  <!-- Import Google Icon Font -->
  <link href="https://fonts.googleapis.com/icon?family=Material+Icons" rel="stylesheet">
  <!-- Import materialize.css -->
  <link href="CDN OR PATH TO NODE_MODULES.css" rel="stylesheet">
</head>
<body>
  <!-- Import materialize.js -->
  <script src="CDN OR PATH TO NODE_MODULES.js"></script>
  <!-- And then your bundled js -->
  <script src="path/to/your/bundle.js"></script>
</body>
```
